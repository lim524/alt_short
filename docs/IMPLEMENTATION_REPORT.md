## 실행한 검사

- `npm test`: **34개 통과, 5개 파일**.
- `npm run typecheck`: 통과. 초기 체크아웃에서도 생성 타입을 확보하도록 `next typegen`을 포함했습니다.
- `npm run build`: 통과. 홈 정적 렌더와 4개 동적 API 경로 생성.
- `npm run test:e2e`: **2개 통과**. Chromium 데스크톱과 iPhone 13 크기의 WebKit에서 합성 fixture로 스캔·근거 펼치기·캔버스 생성·숫자 수정·저장·수정 버전 재열기·추천값 복원·새로고침 후 원본 유지 확인. Chromium에서는 가격선 손잡이 드래그도 확인했습니다. 최종 E2E 중 브라우저 pageerror 없음.
- `npm audit --omit=dev`: **취약점 0개**.
- `node scripts/verify-live.mjs`: 실제 공개 API로 아래 결과 확인. 테스트 fixture 수치는 포함하지 않았습니다.

브라우저 테스트 중 발견한 손잡이 겹침·캔버스 위 표시 순서·제거된 차트 접근 오류를 수정하고 재실행했습니다. DefiLlama 이력 응답이 약 9.8MB여서 현재 TVL 전용 응답으로 변경했고, 선택적 `methodology: null` 필드가 필수 수치 검증을 방해하지 않도록 수정했습니다. 실패 자료를 0으로 대체하지 않습니다.

- `src/lib/domain.ts`: 외부/저장 데이터 스키마, 전략·위험 가정·신호 스냅샷.

## 검증하지 않은 사항

1. iPhone 실물 Safari의 손가락 드래그·백그라운드 중단·저장소 퇴거. WebKit 에뮬레이션을 실제 기기 검증으로 간주하지 않습니다.
2. 유료 OpenAI 모델 호출과 특정 모델의 출력 품질·청구 금액. 서버 키·모델이 없는 상태의 정상 비활성화와 입력/출력 검증은 검사했습니다.
3. 실제 Vercel 배포. 커넥터 팀 목록이 비었고 로컬 CLI에 인증 정보가 없어 배포하지 못했습니다.
4. 백테스트·수익성·예측 확률·실제 체결. 단위 fixture로 확인한 신호 전이는 전략 수익의 증거가 아닙니다.
5. 인증·클라우드 저장·기기간 동기화·무기한 백그라운드 감시.

GitHub 업로드와 원격 CI 상태는 저장소 링크 및 최종 작업 보고에서 별도로 확인합니다.
