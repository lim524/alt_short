# UI 개편 · 2026-11-03

사용자가 제공한 두 이미지의 밝은 배경, 검은색 주요 버튼, 분홍·하늘·회색 요약 카드, 비교 가능한 후보 행을 기준으로 재구성했습니다. `plan.md`의 어두운 테마 선호보다 후속 UI 요청을 우선했습니다. 계산·점수·보관 방식과 실제 데이터 경로는 유지합니다.

## 화면

- 데스크톱: 고정 사이드바, 대시보드·스캔·관심 종목·분석 기록·설정 탐색. 넓은 화면에서 리스트/상세를 나란히 표시합니다.
- 모바일: 큰 제목, 터치 가능한 실행 버튼과 하단 탐색. 320px에서도 가로 스크롤이 생기지 않도록 확인합니다.
- 요약 카드: 실제 기준 점수 이상 후보, 관심 종목, 저장된 분석 수. 미수신 후보 수는 `—`입니다. 배경 SVG는 장식이며 시장 시계열을 표현하지 않습니다.
- 후보 리스트: 현재가·24h 변동률·점수 열, 관심 표시, 요인 요약·자료 충분성, 분홍색 선택 행. 수익 확률로 표현하지 않습니다.
- 상세: 흰색 차트, 파란 상승/붉은 하락 캔들, 원본 시세·시각, 근거 기반 요약, 원본 정보 펼치기, 기존 선 편집·위험 설계·근거·연구 패널.

## 모션

CSS transform/opacity를 중심으로 적용하며 추가 애니메이션 라이브러리는 설치하지 않았습니다.

- 카드 진입: 550ms, 카드 간 55ms 지연.
- 후보 행 진입: 350ms, 행별 짧은 순차 지연(최대 210ms).
- 페이지·탭 전환: 500ms 이하의 작은 상승·페이드.
- 카드 호버: 화살표·장식의 작은 이동, 버튼 누름과 관심 표시 반응.
- 스캔 실행 중: 회전 상태 아이콘·진행 선, 첫 데이터 수신 전 스켈레톤. 스캔 중지로 종료됩니다.
- `prefers-reduced-motion: reduce`에서는 진입·회전·스켈레톤 모션과 부드러운 스크롤을 제거하고 동일한 정보/기능을 제공합니다.

## 참고

- 사용자 첨부 이미지 2개: 레이아웃·색·정보 위계의 주된 기준.
- [Linear](https://linear.app/): 제품 인터페이스의 탐색 구조와 간결한 정보 구성 참고.
- [Vercel Web Interface Guidelines](https://vercel.com/design/guidelines): CSS 우선, transform/opacity, 명시적 transition 속성, reduced motion, 초점 표시와 기기별 검증 참고.
- [Material Motion](https://m3.material.io/styles/motion/overview/how-it-works): 업무용 화면에 맞춘 절제된 모션 원칙 참고. Material 라이브러리를 적용하거나 해당 사이트의 애니메이션을 복제하지 않았습니다.

## 검증

- 기존 단위/API 테스트 **34개 통과**, 타입 검사·프로덕션 빌드 통과.
- 기존 스캔→근거→선/숫자 편집→저장→원본 복원 E2E 유지.
- 추가 UI E2E를 포함해 **4개 통과**: Chromium 데스크톱과 iPhone 크기 WebKit에서 탐색·관심 목록·실제 집계·화면 넘침·동작 줄이기 확인. 1680px 화면 캡처와 320px 폭 넘침 검사도 포함합니다.
- 캡처는 `test-results/`에 생성하며 합성 데이터에는 실제 시세가 아님을 화면에 표시합니다. 기밀/실사용 기록을 캡처하거나 원격 저장소에 올리지 않습니다.
- WebKit의 iPhone 크기 에뮬레이션이며 실물 기기 수동 검증은 별도입니다.
